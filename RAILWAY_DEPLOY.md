# Railway Deploy Guide for WinTech AI

## Step-by-step migration from Netlify to Railway

### 1. Create Railway account
- Go to https://railway.app
- Sign up with GitHub (recommended)

### 2. Create new project
- Click "New Project"
- Select "Deploy from GitHub repo"
- Choose wintechia/wintech (main branch)

### 3. Add PostgreSQL database
- In the project, click "New" -> "Database" -> "Add PostgreSQL"
- Railway will auto-create DATABASE_URL

### 4. Configure environment variables
In Railway dashboard -> Project Settings -> Variables, add:

Required:
- DATABASE_URL = (auto-generated by Railway PostgreSQL)
- NEXTAUTH_URL = https://your-app.railway.app
- NEXTAUTH_SECRET = any-random-string-generate-one

Optional (APIs - add keys from Netlify or generate new ones):
- GROQ_API_KEY = (from console.groq.com)
- OPENROUTER_API_KEY = (from openrouter.ai)
- ELEVENLABS_API_KEY = (from elevenlabs.io)  
- DEEPGRAM_API_KEY = (from deepgram.com)
- RESEND_API_KEY = (from resend.com)
- FROM_EMAIL = WinTech AI <hola@wintech.agency>
- ADMIN_EMAIL = wintech.ia@gmail.com

### 5. Deploy
- Railway auto-deploys on every push to main
- First deploy: ~3-5 minutes

### 6. After deploy
- Run seed to populate DB:
  Railway dashboard -> your service -> "Railway CLI" or
  locally: npx prisma db push (with Railway DB URL)

### Free tier limits:
- $5/month free credit
- 500 hours execution time
- 1GB RAM per service
- Shared CPU
- PostgreSQL included (512MB storage on free tier)

### Advantages over Netlify:
- Everything in one platform (no separate DB service)
- Persistent server (no cold starts like serverless)
- Better for Next.js App Router
- Includes PostgreSQL out of the box
